# Aurora IW4x

<img src=".github/assets/readme/icon.png" align="right" width="100" height="100">

This fork of IW4x is maintained by Aurora to focus modders first and be unrestricted from the main repository. This fork is always pulling in upstream updates, meaning you can enjoy the latest features from IW4x while using the Aurora fork!

To learn more about IW4x itself, [check the original IW4x repository out.](https://github.com/iw4x/iw4x-client) <b>This includes compiling the source code, which they have a guide on.</b>

To learn more about Aurora IW4x's fork or have any requests or questions, you can join [the Aurora discord here.](https://discord.gg/6pSNTjtTCG)

## New features with Aurora

- Re-added old `reloadmenus` command *(technically unstable, but benefits modders for convenience of .menu modding)*
- Check if zone exists before running `loadzone`
- Added `take` command
- Added `give ammo` command, which fills up all weapons' ammo
- Added `listassetpool` command

### Planned for the future
- IMGUI for exploring asset pools, limits, etc.
- vision editor
- changing sv_cheats flags?
