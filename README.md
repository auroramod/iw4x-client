# Aurora IW4x

<img src=".github/assets/readme/icon.png" align="right" width="100" height="100">

This fork of IW4x is maintained by Aurora to focus modders first and be unrestricted from the main repository. This fork is always pulling in upstream updates from the main repo so you can enjoy the latest IW4x while using Aurora's fork!

To learn more about IW4x itself, [check out iw4x-client here.](https://github.com/iw4x/iw4x-client) This includes compiling the source code.

## New features & fixes

- Re-added old `reloadmenus` command *(technically unstable, but benefits modders for convenience of .menu modding)*
- Check if zone exists before running `loadzone`
- Added `take` command
- Added `give ammo` command, which fills up all weapons' ammo
- Added `listassetpool` command
- Fixed map entities overriding not checking the right file
- Removed client-side filtering of "bad" server names

### Planned for the future
- IMGUI for exploring asset pools, limits, vision editor, etc.
